# Upgradeos-site
# 🚀 UpgradeOS Website

> **The official corporate website for UpgradeOS.**

UpgradeOS is a modern technology company building software that helps people simplify and improve their financial lives. This repository contains the official company website—not the Ledger application itself.

The website showcases the UpgradeOS ecosystem, company vision, products, roadmap, founder story, blog, and future direction through a premium, modern user interface inspired by Apple, Stripe, and OpenAI.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/upgradeos.git
```

Navigate into the project:

```bash
cd upgradeos
```

Open the project with VS Code.

If you're using Live Server:

```bash
Right Click → Open with Live Server
```

Or simply open `index.html` in your browser.
